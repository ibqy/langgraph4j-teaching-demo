# 能力与边界

这是一套学习项目，不是可直接暴露到公网的工作流平台。代码、测试和文档共同解释一个机制；任何“已实现”都需要区分引擎能力、教学实现和生产保障。

## 本项目真实执行什么

- 原生 LangGraph4j `StateGraph` 的节点、条件边、回边、并行与子图。
- 原生 Channel 与 Reducer 的合并行为。
- `MemorySaver` 的检查点保存、历史查询、threadId 隔离与审核恢复。
- LangChain4j 模型请求/响应与 LangGraph4j 的工具执行集成。
- Spring Boot 本地 HTTP 接口与节点事件 SSE。
- 对应的自动化测试；模型供应商的真实回答不属于离线测试保证范围。

## 什么是模拟

工单知识、研究材料和业务入账都使用本地确定性数据。模型默认实现会明确标记离线教学，不代表推理、检索准确率或模型能力。研究报告中的来源 ID 指向课程本地样本，不意味着访问过实时网页。

重试与幂等是课程展示的应用逻辑，不是声称引擎自动提供所有外部调用的 exactly-once 保证。

## 不提供的生产保障

| 范围 | 当前边界 | 生产环境需要考虑 |
|---|---|---|
| 状态存储 | 当前 JVM 内存 | 持久化 saver、备份、版本迁移 |
| 审批者身份 | 本地接口传入决定 | 登录、权限、审批归属、审计 |
| 执行隔离 | threadId 与进程内记录 | 租户隔离和跨实例一致性 |
| 防重 | 单次执行内的业务状态 | 数据库唯一键、事务、幂等键 |
| 外部副作用 | 本地模拟 | outbox、补偿、幂等接口 |
| 运行记录 | 有界进程内保留 | 持久化、清理策略与配额 |
| 模型调用 | 可选供应商配置 | 成本限额、脱敏、速率控制 |
| 资料可信度 | 固定教学样本 | 检索权限、时效性和引用核验 |

## 安全使用

1. 默认仅监听 `127.0.0.1:8099`，不要直接改成公网监听用于多人审批。
2. API Key 通过环境变量提供，不写入源码、前端配置、截图或提交记录。
3. 不把真实客户工单、财务凭据或个人信息发送给教学模型。
4. 恢复接口只允许提交批准/拒绝，不开放任意状态覆写。
5. 不将 executionId 或 threadId 当作身份认证。知道标识符并不应在生产系统中获得审核权限。
6. 网站托管的是静态文档，不启动 Java 服务，不提供在线审批或模型执行。

## 恢复不等于撤销

检查点恢复可以让引擎从某个位置继续，但无法撤销已经发出的邮件、支付或第三方请求。即使状态回到旧位置，外部世界也不会自动回滚。先识别副作用，再设计幂等或补偿，是比“加一个 saver”更重要的工程步骤。

## 版本锁定

本课程固定 LangGraph4j 1.9.0。升级前至少重新验证 Reducer、并行汇合、多级审核恢复、子图结束事件和模型工具协议。不要只以编译成功作为升级完成依据。
